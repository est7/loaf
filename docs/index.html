① 协议三纪律

违反任一条都让其它结构失去意义。

PRINCIPLE 15a · TRUTH MODEL
Single typed journal + reducer-derived projection
Canonical truth = .loaf/<feature>/journal.jsonl(append-only,typed envelope)+ attachments/<entry_id>/(per-entry sidecar)+ loaf.config.json。所有 state.json / tasks.json / evidence.json / findings.json / spec.md / lessons.md 均是 reducer 从 journal entries 重建的派生投影,落 snapshots/*.json 或 markdown,允许 stale,gate 永远不读。
PRINCIPLE 15 · MUTATION DISCIPLINE
Per-session lock + 10-step journal transaction
所有 mutation 必须经 loaf <cmd> 在 per-feature .lock 内完成 10-step transaction(acquire → preflight → sidecar → final validate → append → post-apply → snapshot rebuild → registry refresh → release)。skill / sub-agent / 外部脚本不得直写任何 .loaf/<feature>/ 路径。
PRINCIPLE 14 · PROTOCOL vs SKILL
协议管 shape,skill 管 content
协议层只校验结构:可验证性 / ID 引用 / 写权限 / 状态机转移合法性。语言风格、ceremony preset、prompt 模板、workflow 编排是 loaf-skill 的事,不进协议。

⑤ Truth model · 4 层 authority

Gate 永远只读 Canonical;其它三层任何时候都允许 stale。Reader 读 Derived projection 必须先过 Gate #5 fast check,mismatch 直接 exit 2,绝不静默 fallback。

Reader contract(Gate #5 fast check)

步骤检查失败行为
1读 _meta.last_applied_seq作 "as-of" 版本号 wrap stdout footer
2读 _meta.last_entry_offset + last_entry_line_hashO(1) fast tail check
3验 hash 与 journal 末行 sha256 是否一致mismatch → exit 2 SNAPSHOT_STALE_REBUILD_REQUIRED,提示 loaf doctor --rebuild
4fast check 过parse snapshot,正常返回

绝不静默 fallback 到 cached snapshot;reader 永远要么读到一致版本,要么 hard fail。

⑥ §11.2 · 10-step journal mutation transaction

每个 mutator 命令在 per-feature .lock 内执行 10 步;任一步 fail 释放 lock,journal 未 append,reader 看不到部分状态。Crash 在每步的恢复路径见右栏。

Single-entry mutation 与 batch mutation 走同一 10-step 路径;batch 在 step 3 分配 batch_id + batch_index + batch_count,step 6 一次 write() 拼接所有 entry。

⑦ 五个 implementation gates

ADR-0005 Accepted-with-implementation-gates 的硬约束;每个 gate 在某个 stage 落地,配独立 acceptance test。

#1

validateTransition shared helper

event:phase_advanced 与 gate:decided 复用同一 transition validator(src/core/reducer/transition.ts);两个 kind 的 apply 路径不得各写一套 if/else。

📌 Stage 2
tests/core/per-kind-substate.test.ts
#2

Final-entry-only append

step 5 final validate 通过后,唯一被允许 append 的 entry 是 step 5 验证过的 final-form。step 6 不得重新序列化 / 不得重算 AttachmentRef / 不得修改 validated 字段。

📌 Stage 1 + Stage 4 verify
tests/core/final-validation.test.ts
#3

Migration sidecar manifest-only

migration:snapshot_imported 的 journal payload 只允许 含 AttachmentRef manifest;绝不含 artifact 正文。.strict() Zod refine 保证 schema 层闭环。

📌 Stage 5
tests/core/v0.0.x-migration.test.ts
#4

Batch-aware tail recovery

doctor 启动期 tail recovery 必须以 batch 为单位:
· 单 entry partial → truncate 单 entry
· batch incomplete → truncate 整个 batch 到 batch 第一个 entry 之前

📌 Stage 3
tests/core/tail-corruption.test.ts(7 场景)
#5

Snapshot read fail-fast

CLI read 命令读 snapshots/*.json 必须先做 fast check;mismatch → exit 2 SNAPSHOT_STALE_REBUILD_REQUIRED,禁止静默 fallback。

📌 Stage 6
