## Closure

The inventory is generated from every top-level exported declaration in `docs/schemas.ts`, in declaration order. A value and its inferred type are separate exports and therefore separate rows.

Verdicts apply only where `duplicate-of` names an existing runtime semantic owner:

- `keep-runtime`: the runtime owner survives dissolution; the docs copy is removed after consumers move.
- `keep-docs`: the docs behavior would be promoted into the domain home.
- `intentional-change`: the copies differ deliberately; migration must preserve the stated runtime boundary rather than silently merging behavior.
- `n/a`: no runtime duplicate is currently identified; the export moves to its assigned domain home.

## Required divergence pins

These are characterized in `tests/core/schemas-divergence-characterization.test.ts` with `safeParse` assertions before any production move.

| Group                              | Docs behavior                                                          | Runtime behavior                                           | Dissolution decision |
| ---------------------------------- | ---------------------------------------------------------------------- | ---------------------------------------------------------- | -------------------- |
| Evidence identity and summary      | Full entry uses `evidence_id`; add/full summary is string-only.        | Full payload uses `id`; summary accepts string or sidecar. | keep-runtime         |
| VisualContract and SpecFrontmatter | Visual unknown keys are stripped; missing `adr_refs` defaults to `[]`. | Visual is passthrough; `adr_refs` is required.             | keep-runtime         |
| Ceremony                           | `{}` parses by applying six defaults.                                  | All six fields are required.                               | keep-runtime         |
| JournalEntry                       | Reserved `signature` is accepted.                                      | Strict envelope rejects `signature`.                       | keep-runtime         |

The same test file snapshots exact current JSON Schema output for all ten public emit surfaces: five mutator inputs and five artifacts. Those snapshots are an output-compatibility gate, not a claim that the docs copies are runtime-canonical.
